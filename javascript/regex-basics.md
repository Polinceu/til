# JS：正则够用写法，test / match / replace 三件套

正则不用全背，记住三个方法和几个常用元字符，日常够用了。

## 三个方法

```js
/^\d{11}$/.test("13800138000");              // true，校验手机号位数
"order-2026-11-09".match(/\d{4}-\d{2}-\d{2}/); // 提取日期
"hello world".replace(/(\w+) (\w+)/, "$2 $1");  // "world hello"，$1/$2 是分组
```

## 常用元字符

- `\d` 数字，`\w` 字母数字下划线，`\s` 空白字符。
- `^` 开头、`$` 结尾：校验时两个都要写，不然 `\d{11}` 会匹配到长串的一部分。
- `+` 一个或多个，`*` 零个或多个，`?` 零个或一个，`{n,m}` 指定次数。

## 坑

- 带 `g` 的正则用 `test` 是有状态的：`lastIndex` 会接着上次的位置继续，
  同一个正则对象连续 `test` 可能一真一假，校验时别加 `g`。
- 想匹配字面意义的 `.`、`*`，前面加反斜杠转义。
