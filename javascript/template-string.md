# JS：模板字符串，不只是拼字符串

```js
const name = "a";
const n = 3;

// 插值
console.log(`你好，${name}，你有 ${n} 条消息`);

// 多行字符串，不用 \n 拼接
const html = `
  <div>
    <span>${name}</span>
  </div>
`;

// 表达式也能插
console.log(`1 + 2 = ${1 + 2}`);  // 1 + 2 = 3
console.log(`状态：${n > 0 ? "有" : "无"}`);
```

- 反引号里 `${}` 放任意表达式，函数调用也行。
- 多行模板字符串会保留换行和缩进，拼 HTML 时注意前导空格。
- 嵌套模板字符串时，内层也要用反引号，别混成单引号。
