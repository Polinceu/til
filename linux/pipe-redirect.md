# Linux：管道和重定向，一次讲清

```bash
cmd > file      # 标准输出写进文件（覆盖）
cmd >> file     # 标准输出追加到文件
cmd 2> err.log  # 标准错误写进文件
cmd > out.log 2>&1  # 输出和错误都进同一个文件
cmd < input.txt # 把文件当标准输入
cat a.txt | grep foo | wc -l  # 管道：上一个的输出是下一个的输入
```

- `>` 是覆盖，`>>` 是追加，用错了会清空文件。
- `2>&1` 的顺序有讲究：`> file 2>&1` 是对的，反过来写不行。
- 管道 `|` 传的是**文本流**，不是文件名，`grep` 这类命令才能直接接。
